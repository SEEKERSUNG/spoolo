## 功能

- **实时取景**：调用摄像头（`getUserMedia`），前后摄切换，取景窗按手持方向裁切（竖屏 3:4、横屏与桌面 3:2），所见即所得。
- **换卷即时生效**：转动顶盖旋钮或用胶卷库点选，取景画面立刻变成该乳剂的色彩。
- **机械手感**：合成音效（快门双响 + 低频 thunk、旋钮咔哒、回卷声，全部由 WebAudio 现场合成，不含音频文件）；曝光补偿 ±2EV 以 1/3 档步进；定时拍摄、构图网格、日期打印。
- **一卷 36 张**：计数器随拍摄递减，满卷自动回卷，也可手动回卷。
- **暗房冲印**：拍下后走「曝光 / 显影 / 定影 / 干燥」四步动画，成片按 1920px 长边烘焙，带颗粒、光晕、暗角、漏光与日期水印。
- **影集**：IndexedDB 本地存储，灯箱查看底片信息、保存到本地、删除（6 秒内可撤销）。
- **导入冲洗**：把本地照片当作底片送进暗房，用任意一卷冲印。
- **优雅降级**：没有摄像头或未授权时，自动改用内置示范底片并提示重试。
- **响应式与无障碍**：桌面为常驻暗房侧栏，窄屏为底部抽屉；空格快门、`G` 网格、`D` 日期、`M` 快门声、`Esc` 关闭面板；旋钮为 `role="slider"`、开关为 `aria-pressed`，并遵循 `prefers-reduced-motion`。

## 色彩引擎

- 分通道 256 级 LUT：对比 / 提亮 / 伽马 / 增益，配合 `tanh` 高光肩部做柔和高光压缩；黑白乳剂走单色 LUT。
- 阴影与高光分离调色（split-tone），按亮度加权，用来做青绿阴影、暖调高光这类"胶片味"。
- 颗粒：`Math.imul` 哈希噪声，按亮度调制（暗部更明显），颗粒尺寸可调。
- 光晕 halation：半分辨率亮部遮罩 → 两遍分离式盒式模糊 → screen 混合，可设阈值、半径与颜色。
- 暗角与漏光由径向遮罩与渐变合成。
- 曝光补偿直接折进 LUT，与拍摄时一致。
- **预览与成片一致性**：预览只做逐像素色彩（颗粒 / 暗角 / 漏光由 CSS 覆盖层承担，保证取景帧率），成片走完整管线，两者参数同源。预览分辨率按帧耗时自适应（0.32–0.9 倍）。

## 本地运行

```bash
python -m http.server 8123
```

然后访问 <http://localhost:8123/>。

> `getUserMedia` 只在 HTTPS 或 `localhost` 下可用。直接双击 `index.html`（`file://`）时多数浏览器会拒绝摄像头权限，此时用页面上的「换一张示范底片」即可走通完整的拍片与冲印流程。
> 手机也一样：用局域网 IP 以 http 打开会被浏览器直接屏蔽镜头，**必须走 HTTPS**（GitHub Pages 的地址天然是 https），进页面后点一下屏幕即会弹出授权。

## 目录结构

```
index.html          机身结构：顶盖 / 取景器 / 胶片仓 / 控制台 / 暗房 / 灯箱
css/base.css        设计令牌、布局、机身与取景器
css/ui.css          旋钮、功能键、快门、胶卷卡、影集、抽屉等组件
js/films.js         十种乳剂预设 + LUT / 颗粒 / 光晕 / 暗角像素管线
js/store.js         IndexedDB 底片存储（不可用时降级为内存）
js/app.js           取景、快门、冲印、胶卷与影集、导入、音效
assets/samples/     无摄像头时使用的示范底片
```

## 部署

仓库是纯静态站点，GitHub Pages 直接在 **Settings → Pages** 选择 `main` 分支根目录即可发布。
